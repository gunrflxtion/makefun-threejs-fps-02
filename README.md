# IRONLINE PROTOCOL

A round-based tactical FPS in three.js: 5v5 at an industrial port terminal — plant the charge at SITE A or eliminate the RUST team, earn money each round, and spend it on rifles, SMGs, a sniper, a shotgun, grenades and armor. Bots walk lanes, hold positions, react to gunfire, and work the objective.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click to play — WASD to move, mouse to look, click to fire, R to reload, E (hold) to plant at SITE A, B for the buy menu, G for a grenade.
